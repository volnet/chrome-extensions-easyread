# 媒体图片与稍后阅读分组

- 媒体内增加全部、视频、音频、图片四个分类，支持方向键切换。分类切换只隐藏卡片，不销毁下载进度；预览播放队列限定在当前分类内。
- 图片来源为当前文档 img 的 currentSrc/src/data-src 所指向的 HTTP(S) 资源，按 URL 去重并排除扩展自身 UI。支持图片预览、尺寸、来源及下载；已知图片扩展名正确保留，无扩展名 URL 在下载时尝试读取 Content-Type。不能判断格式时保留未知图片扩展名，不伪装成 MP4。
- 不包含 CSS 背景、canvas、内联 SVG、data/blob URL 或未加载的跨域框架图片。大量图片采用懒加载预览，不自动为每张图片发送额外尺寸探测请求。
- 设置中未读（含阅读中）在上方，已读在下方、默认折叠。已读展开后按每页 50 条渲染；不迁移或修改既有 status 值。
- 移除“导出文件已准备好”成功提示的调用，保留错误反馈和文件下载。
