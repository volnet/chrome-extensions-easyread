# EasyRead 2.0.0：设置分类与按需诊断

## 本次行为

| Before | After | Why |
| --- | --- | --- |
| 开发版诊断在页面右下角显示浮层 | 常规中的“诊断工具 / Diagnostic Tool”滑块；默认关闭；列表集中在设置页 | 不遮挡正文，采集权交给用户 |
| 多处独立错误下载入口 | 主窗口圆叉：一条直接下载，多条打开 `setting.html#diagnostics`；设置页逐条下载 | 统一入口且保留单次完整堆栈 |
| 截图选择范围、格式后再操作 | 复制窗口、复制整页、保存窗口、保存整页四个按钮 | 减少临时选项及点击步骤 |

## 诊断存储与隐私

- 开发版、正式版均使用持久化的 `diagnosticsEnabled` 开关，默认关闭。此项取代此前“仅开发版具有诊断能力”的构建开关。
- 沿用扩展本地存储 `chrome.storage.local`（不是被访问网站的 `window.localStorage`），兼容 MV3 worker；不增加网络请求、权限或远程日志。
- 保留已有 `easyreadDevelopmentErrors` 存储键。后台单一写入队列串行保存最近 100 条报告，清空操作也经过该队列。
- 关闭时移除 error/unhandledrejection 监听及控制台包装，清空当前诊断阶段缓存，不删除旧报告。已有页面同步响应配置，无需重开页面才能停止采集。
- 单次下载使用 `easyread-error-v1`，包含一条报告、原始 error.stack、cause、上下文、页面和阶段信息；兼容历史报告。下载只在用户点击时发生。
- 对结构化密码、Cookie、Authorization、访问令牌字段做脱敏；报告仍可能包含页面/资源地址，分享前应检查。
- 截图偏好使用新增键 `captureImageFormat`，值为 `png` / `jpeg`；不改动已有历史、重点、批注及导入导出字段。

## 验证

- 40 项单元测试、ESLint、基线检查和开发/正式版构建通过。
- 隔离 Edge 中文开发版、英文正式版：设置开关、弹窗及内容脚本跨上下文采集、原始堆栈和 cause 的真实 JSON 下载、单条/多条入口、深链接定位、即时关闭、刷新后旧报告保留及清空。
- 设置名称顺序、联系方式位置、JPG 偏好刷新保留、四个截图按钮的范围/保存格式/剪贴板 MIME 路由通过；此处对截图消息及剪贴板写入做桩验证，不宣称重新验收完整页面拼接或真实系统剪贴板图像。
- 原有真实媒体下载、批注、备份导入导出和 500 条分页回归通过。
- 真实工具栏弹窗逐帧布局回归通过；保留此前固定外框、面板内部滚动的实现。

## 后续维护规则

外部一级功能与设置 Tab 同名、同顺序；二级配置按外部功能顺序组织。外部导航变更时同步调整设置及中英文资源，已写入仓库 `AGENTS.md`。

重新加载扩展后刷新已打开网页，才能清除旧版本已经插入的诊断浮层。
