# 媒体预览设置与笔记角标

- 设置 → 媒体：自动播放（关闭 / 按序播放 / 同时播放〔静音〕），静音滑块。两项默认关闭。
- 本地偏好键为 `mediaAutoplay`（off/sequential/simultaneous）、`mediaMuted`（boolean）；不改旧数据结构，不新增权限。
- 设置即时作用于主窗口预览。按序播放在当前预览结束后启动下一条，不循环；同时播放强制静音。离开媒体 Tab 暂停预览，不控制原网页视频。
- HTML video/audio 与 HLS 预览接入播放控制；Vimeo 内嵌播放器通过限定来源和窗口的事件消息衔接结束、暂停和音量。自动预览不会弹出新的权限申请。
- 浏览器的有声自动播放限制仍然有效，被拦截时需手动播放。无法播放、未获授权或无法返回结束事件的资源不保证自动连续播放。
- 笔记 Tab 角标统计当前页面全部已保存笔记（引用及整页笔记），编辑草稿不计数；零条隐藏。新增、删除和外部存储变更均刷新角标。

验证：53 项单元测试，包含默认值、顺序衔接、同时静音、离开暂停；隔离 Edge 实际本地 MP4 检查设置存储与即时生效，中英文 UI 和原生弹窗稳定性检查。未声称已验证所有远程视频网站。
