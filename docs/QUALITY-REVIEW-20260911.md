## 视觉审查与实现

按 emil-design-eng 的设计工程原则处理层级、反馈与可访问性；借鉴桌面系统的克制感，不引入外部字体、图标库或远程依赖。

| Before | After | Why |
| --- | --- | --- |
| 浮窗、设置、记录各自使用字体、描边、按钮和阴影 | 统一中性色、字体、圆角、轻描边、按钮与焦点样式 | 减少界面之间的割裂感 |
| 橙色渐变标题、重复橙色装饰 | Logo 和少量状态保留品牌色，正文及工具图标使用中性色 | 让内容优先，降低视觉负担 |
| 图片充当按钮，部分操作只能用鼠标 | 真实按钮、统一 SVG 线性图标、可读名称、Tab 方向键/Home/End | 改善键盘和辅助技术操作 |
| 截图选项一行挤压、固定文本宽度 | 分组布局、长文本换行、400px 窄窗检查 | 避免按钮和内容溢出 |
| 媒体信息与动作层级不稳定 | 左侧 1/3 等比例预览，右侧信息在上、自然尺寸按钮在下 | 保留预览定位，不变成大型播放器 |
| 批注偏暖、浮层阴影重、收起 Logo 布局不一致 | 中性浅色玻璃面板、紧凑工具栏、统一卡片与 flex Logo 入口 | 更安静的阅读环境 |
| 高频列表放大动画、部分 reduced-motion 遗漏 | 删除夸张动画，保留短按反馈，键盘与减少动态模式不做移动动画 | 响应更直接，减少干扰 |
| 设置中的导出、覆盖和清空混杂 | 分类 Tab、折叠模板、高风险操作独立分组并确认 | 降低误操作风险 |

## 已修复的问题

1. 合并备份时对旧 URL 先标准化再取原对象，导致大小写/锚点不同的键取值丢失；现在使用原键读取、现有规则归档。
2. 首次导入重点错误创建数组；现在保持页面字典结构。
3. 重复导入相同稍后阅读条目会追加重复项；现在跳过同一条目。
4. 新视频进度在历史合并时遗漏；现在保留时间更新的进度。
5. 导入存储 Promise 未被等待，异步错误逃过回调；修复等待和错误返回。存储更新返回的 Promise 也等待实际持久化。
6. 导入缺少基本结构检查；在写入前拒绝畸形集合及危险键，保留旧版空集合和未知设置键兼容性。
7. 普通 `%` 使旧重点显示/Markdown 导出失败；使用兼容解码。正文兼容回退不再制造开发错误日志。
8. Markdown 中 `$&` 等字符被当成替换语法；改用函数替换保留原文。
9. 同名 Markdown 文件在 ZIP 中覆盖；重复文件名增加序号。ZIP 对象 URL 在启动下载后释放。
10. “阅读中”的条目无法勾选完成，且可被重复添加；修复两处状态判断。
11. 稍后阅读逐条请求当前标签，增加长列表延迟；改为每次渲染请求一次。
12. 浮窗空状态、旧列表及重复重点渲染残留；增加清理及就地更新。阅读记录到达后刷新浮窗，移除猜测性的 250ms 等待。
13. 特殊页面缓存被错误当作有效网页；严格检查 HTTP(S)，禁用不支持的保存按钮，并正确显示空媒体状态。
14. 记录排序反复扫描阅读时间，且展开超大时间数组可能栈溢出；预计算排序值，用迭代扫描。18 万条单页访问时间已测试。
15. 导入记录中的非网页链接可能生成可执行导航；记录、稍后阅读和来源链接限定 HTTP(S)。
16. 下载轮询抛错可能无法结束、定时请求重叠；改为串行轮询，异常进入原错误处理。
17. 保存/复制连续点击可能并发启动多个任务；任务期间禁用相关按钮。设置写入期间锁定相关控件。
18. 批注写入失败后保存按钮无法恢复；新增及编辑均显示反馈并恢复按钮。
19. 设置、工具按钮缺少明确标题/标签，浏览器扩展默认字体覆盖正文尺寸；补齐语义和明确字体继承。

## 后续修复：切换“保存网页”时弹窗抖动

在隔离 Edge 中通过 `chrome.action.openPopup()` 打开真实工具栏弹窗，复现了浏览器自动尺寸计算与 `max-width: 100vw` 的循环依赖。原实现切换到保存页后，逐帧宽度在 360、444、528、612 像素等数值之间变化，并反复跨越窄屏断点；普通扩展标签页的固定视口测试无法发现该问题。

| Before | After | Why |
| --- | --- | --- |
| 外框按当前 Tab 的内容及自身视口反复计算尺寸 | 明确 560 × 580 的首选外框，内容高度适配浏览器实际可用视口 | 消除自动尺寸计算的循环依赖，切换不改变外框 |
| 内容增加时整窗滚动、重排 | 标题、Tab 栏和页脚保持位置，仅活动面板内部滚动 | 保存过程和长错误信息不会挤动窗口；媒体卡片仍按内容紧凑排列 |
| 仅在普通扩展标签页检查最终画面 | 增加真实工具栏弹窗逐帧回归 | 同时检验切换过程与最终状态，避免漏掉尺寸振荡 |

验证结果：

- `npm test`：38 项通过；`npm run build:unpacked`：开发版、正式版构建通过。
- `npm run test:popup-layout`：中文开发版、英文正式版分别检查 117 帧，弹窗宽高、正文宽度及导航位置始终相同。测试环境浏览器限制高度为 514 像素，含浏览器侧边空间的实际外框为 567 × 514；不是通过测试工具强设视口。
- 覆盖反复切换三个 Tab、长过程/错误提示、滚动到 Markdown 保存按钮、页脚可见性及方向键切换。
- 原有中英文 UI/MV3 回归再次通过；原合成窄窗检查改为更符合真实弹窗的受限高度检查（560 × 480），验证滚动后的按钮可达性和减少动态效果模式。
